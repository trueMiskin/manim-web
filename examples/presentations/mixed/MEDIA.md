# Example media

These assets were generated for this example and are covered by the repository's MIT license.

- `diagram.svg` and `video-poster.svg` are authored vector geometry.
- `demo.webm` was recorded from a 480×270 canvas with the browser's VP8 MediaRecorder. It contains 36 frames: a radius-35 cyan circle moving from x=60 to x=420 at y=135 against `#102030`. It has no audio and no external source material.
- `tone.wav` is a quiet 0.6-second 440 Hz sine wave, 8 kHz mono PCM. Run `node generate-audio.mjs` to reproduce it.

These files are ordinary portable media assets. No generator runs when the presentation loads or prints.
